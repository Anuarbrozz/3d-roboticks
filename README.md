# ROBO LAB — 6 осьті робот 3D

## Іске қосу (VS Code)
1. ZIP архивті ашыңыз.
2. VS Code → File → Open Folder → `robot6axis_site` папкасын таңдаңыз.
3. Python орнатылған болса, терминал ашып: `python app.py` (Windows-та `py app.py` да болады).
4. Браузерде `http://127.0.0.1:5000` ашыңыз.

Қажет болса Flask орнату: `pip install flask`

## Мүмкіндіктер
- 3D өнеркәсіптік робот модель
- 6 осьтің әрқайсысын slider арқылы бұру
- Авто-демо қозғалысы және Stop
- Home және reset
- Модельді тышқанмен айналдыру және zoom
- Grid қосу/өшіру

Ескерту: 3D графика Three.js CDN арқылы жүктеледі, интернет қосулы болуы керек.
